# theme-impression-memo
制作テーマと印象を整理するブラウザツール。入力内容は端末内に保存します。

## 入出力

- 「入出力」から `theme-impression-memo.json` を保存・読み込みます。JSONのコピーと貼り付けも同じ形式です。
- iCloudへ置く場合は同名のバックアップファイルを更新し、別端末のアプリで手動で読み込みます。ファイルとブラウザの内容は自動では同期されません。
- 読み込み時は「今回の制作へ追加」「今回の制作を置き換える」「今回の制作と設定を復元する」から選びます。設定がないWeb版GPTのJSONは制作内容だけを読み込めます。
- 「入力を消去」は今回の制作と選択を消し、追加した候補語・印象項目は残します。
