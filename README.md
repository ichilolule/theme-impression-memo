# theme-impression-memo

制作テーマと印象を案件ごとに整理するブラウザツール。入力内容はこの端末のブラウザに自動保存され、サイトへ送信されません。

画面上部の案件タブで切り替え、「＋新規」で空の案件を作れます。「クリップボードから新規」は、案件JSONを読み取って別の案件として追加します。ブラウザがクリップボードの読み取りを許可しないときは、「入出力・設定」へJSONを貼り付けて「新規案件として追加」を選びます。タブの「×」は案件を一覧へしまうだけで、削除は「案件一覧」から明示的に行います。

「案件JSONをコピー」は、現在の案件の入力、印象タグ、採用・候補にした語、ギャップ、メモをJSONとしてコピーします。Web版GPTへそのまま貼り付けられます。候補語の一覧や別案件の内容は含みません。共有用のファイルが必要なときは「入出力・設定」から現在の案件だけを保存できます。

「決まっている語から選ぶ」では、入力した語と完全一致する候補語が一つだけなら、その印象項目を自動で選択します。同じ語が複数の項目にある場合や新しい語は、印象タグに登録します。追加した候補語・印象項目は全案件に共通です。

## 全件バックアップ

- 「入出力・設定」の「全件バックアップを書き出す」は、全案件と共通設定を固定名の `theme-impression-memo.json` に保存します。通常の案件切り替えにファイル操作は不要です。
- 対応するChromeでは、最初に保存先ファイルを選ぶと、以後は同じファイルを更新できます。その他のブラウザではダウンロードします。Google Driveへ保存する場合は同期フォルダを選ぶか、ダウンロードしたファイルをアップロードしてください。同期・アップロードの完了はDrive側で確認してください。
- 画面に表示する日時は「最終全件書き出し」です。ブラウザ内の自動保存とGoogle Drive上のバックアップは別です。ブラウザの保存データを消すと端末内の案件は失われるため、定期的に全件バックアップを残してください。
- 全件バックアップを読み込むと、内容を確認した後で現在の全案件と共通設定を置き換えられます。従来の案件JSON、設定のみのバックアップ、旧一体型JSONも読み込めます。

既存の1件分のブラウザ保存データは、最初の案件に自動移行します。移行元の古い保存キーは削除しません。
