# theme-impression-memo
制作テーマと印象を整理するブラウザツール。入力内容は端末内に保存します。

「決まっている語から選ぶ」では、入力した語と完全一致する候補語が一つだけなら、その印象項目を自動で選択します。同じ語が複数の項目にある場合や新しい語は、印象タグに登録します。

画面の「コピー」「保存」「PNG化」から、文章のコピー、制作ごとのJSON保存、PNG保存ができます。依頼者名と案件名があればファイル名は「依頼者名_案件名.json」、私用などで両方空欄なら従来どおり「題材.json」です。案件名だけなら案件名、依頼者名だけなら題材を優先します。使える名前がなければ `テーマ印象メモ.json` にします。ファイル名に使えない記号は「・」に置き換えます。JSONには依頼者名・案件名・題材・テーマ・メモと、採用または候補にした印象だけを含み、未選択の候補語一覧や設定は含みません。

対応するChromeでは、最初の「保存」で制作JSON用のフォルダを選びます。以後は同じフォルダへ保存し、設定画面から変更できます。同じ名前のファイルを既に保存した場合は更新し、別の内容がある場合は上書き前に確認します。

## 入出力・設定

- 「入出力・設定」のバックアップは `theme-impression-memo.json` に追加した候補語・印象項目だけを保存します。制作内容は含みません。JSONのコピーも同じ内容です。
- 最初のバックアップ保存時に固定名のファイルを選び、次回から同じファイルを更新します。設定画面から保存先を変更できます。GoogleドライブやiCloud Driveを使う場合は、それぞれの同期フォルダ内を選んでください。
- 選んだ保存先はこのブラウザ内に記憶します。Chromeの権限が切れた場合は、次の保存時に再許可が必要です。ブラウザの保存データを消すと保存先の再設定が必要です。クラウドへの同期完了は保存先アプリで確認してください。別端末のアプリではJSONを手動で読み込みます。
- 制作JSONは「今回の制作へ追加」「今回の制作を置き換える」で読み込めます。設定バックアップは「追加した候補語・項目を復元」で読み込めます。以前の一体型JSONも読み込み可能です。
- 「入力を消去」は今回の制作と選択を消し、追加した候補語・印象項目は残します。
