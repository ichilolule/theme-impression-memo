# theme-impression-memo

制作テーマと印象を案件ごとに整理するブラウザツール。入力内容はこの端末のブラウザに自動保存され、サイトへ送信されません。

画面上部の案件タブで切り替え、「＋新規」で空の案件を作れます。タブの「×」は案件を一覧へしまうだけです。しまった案件を開き直したり削除したりするときは、「入出力・設定」の「案件一覧」を使います。削除ボタンを押すと確認画面なしで端末内から削除します。

「書き出し」は現在の案件のJSONをプレビューし、「コピー」またはファイルへの「書き出し」を選べます。対応するChromeでは同じ画面の「保存先フォルダを設定」で案件JSONの保存先を選べます。Web版GPTへはコピーしたJSONをそのまま貼り付けられます。JSONには現在の案件の入力、印象タグ、採用・候補にした語、ギャップ、メモだけが入り、候補語の一覧や別案件の内容は含みません。

「読み込み」は画面を開いて、貼り付けた案件JSONを「コードから読み込み」で、個別案件のJSONファイルを「ファイルから読み込み」で現在のタブに反映します。クリップボードの内容は自動では読み取りません。現在の案件に入力済みの内容がある場合は、画面に上書きの警告を表示します。「入出力・設定」の読み込みはバックアップファイル専用で、選んだファイルの内容と置き換わる範囲を確認してから復元できます。

「決まっている語から選ぶ」では、入力した語と完全一致する候補語が一つだけなら、その印象項目を自動で選択します。同じ語が複数の項目にある場合や新しい語は、印象タグに登録します。追加した候補語・印象項目は全案件に共通です。

「印象を選ぶ」の「選択した印象のみ」は、採用・候補にした語だけを項目ごとに表示します。選択を外した語は、この一覧から消えます。

## 全件バックアップ

- 「入出力・設定」の「全件バックアップを書き出す」は、全案件と共通設定を固定名の `theme-impression-memo.json` に保存します。通常の案件切り替えにファイル操作は不要です。
- 対応するChromeでは、名前を付けて保存先ファイルを複数追加できます。例えばGoogle DriveとiCloud Driveの各フォルダで同じ固定名のファイルを選びます。以前に設定した1件の保存先も引き継ぎます。保存先の名前は一覧で変更でき、「解除」は登録を外すだけでファイルを削除しません。
- 案件内容や共通設定の変更から2分後、作業が続く場合も最長5分で各ファイルを更新します。起動時も内容を確認します。Chromeのファイルアクセスが切れた保存先は、その行の「保存」で再許可してください。ファイルが別の操作で更新された場合は、その保存先だけ自動保存を停止します。他の保存先の更新は続きます。
- その他のブラウザでは手動でダウンロードします。画面に表示する「最終保存（いずれかの保存先）」は、この端末から少なくとも1か所へ保存した日時です。ブラウザ内の自動保存とGoogle Drive・iCloud Drive上のバックアップは別です。クラウドへの同期完了は各サービスで確認してください。
- 画面上部の「全件バックアップ」の丸は、緑が登録したすべての保存先ファイルと現在の案件内容の一致、黄が更新待ち・保存先未設定・アクセス再許可待ち、赤がいずれかの保存エラーまたは外部更新による停止を示します。丸を押すと保存先ごとの状態を確認できます。緑はクラウドへの同期完了を意味しません。
- 全件バックアップを読み込むと、内容を確認した後で現在の全案件と共通設定を置き換えられます。設定のみのバックアップは共通設定だけ、旧一体型バックアップは現在の案件と共通設定を置き換えます。個別の案件JSONはホームの「読み込み」で扱います。

既存の1件分のブラウザ保存データは、最初の案件に自動移行します。移行元の古い保存キーは削除しません。
