# theme-impression-memo

制作テーマと印象を案件ごとに整理するブラウザツール。入力内容はこの端末のブラウザに自動保存され、サイトへ送信されません。

画面上部の案件タブで切り替え、「＋新規」で空の案件を作れます。タブの「×」は案件を一覧へしまうだけです。しまった案件を開き直したり削除したりするときは、「入出力・設定」の「案件一覧」を使います。削除ボタンを押すと確認画面なしで端末内から削除します。

「書き出し」は現在の案件のJSONをプレビューし、「コピー」またはファイルへの「書き出し」を選べます。Web版GPTへはコピーしたJSONをそのまま貼り付けられます。JSONには現在の案件の入力、印象タグ、採用・候補にした語、ギャップ、メモだけが入り、候補語の一覧や別案件の内容は含みません。

「読み込み」は画面を開いて、貼り付けた案件JSONを「コードから読み込み」で、個別案件のJSONファイルを「ファイルから読み込み」で現在のタブに反映します。クリップボードの内容は自動では読み取りません。現在の案件に入力済みの内容がある場合は、画面に上書きの警告を表示します。全件バックアップや共通設定の復元は「入出力・設定」から行います。

「決まっている語から選ぶ」では、入力した語と完全一致する候補語が一つだけなら、その印象項目を自動で選択します。同じ語が複数の項目にある場合や新しい語は、印象タグに登録します。追加した候補語・印象項目は全案件に共通です。

## 全件バックアップ

- 「入出力・設定」の「全件バックアップを書き出す」は、全案件と共通設定を固定名の `theme-impression-memo.json` に保存します。通常の案件切り替えにファイル操作は不要です。
- 対応するChromeでは、最初に保存先ファイルを選ぶとその場で保存します。以後は案件内容や共通設定の変更から2分後、作業が続く場合も最長5分で同じファイルを更新します。起動時も内容に差がある場合だけ更新します。Chromeのファイルアクセスが切れた場合は、保存ボタンで再許可が必要です。保存先のファイルが別の操作で更新された場合は、自動保存を停止します。
- その他のブラウザでは手動でダウンロードします。Google Driveへ保存する場合は同期フォルダを選ぶか、ダウンロードしたファイルをアップロードしてください。同期・アップロードの完了はDrive側で確認してください。
- 画面に表示する日時は「最終全件保存」です。ブラウザ内の自動保存とGoogle Drive上のバックアップは別です。ブラウザの保存データを消すと端末内の案件は失われるため、保存先の状態も確認してください。
- 全件バックアップを読み込むと、内容を確認した後で現在の全案件と共通設定を置き換えられます。従来の案件JSON、設定のみのバックアップ、旧一体型JSONも読み込めます。

既存の1件分のブラウザ保存データは、最初の案件に自動移行します。移行元の古い保存キーは削除しません。
