テーマ印象メモ

印象を選び、制作の手掛かりを添えて、チャットへそのままコピーできます。入力はこの端末のブラウザに保存され、サイトへ送信されません。

今回の制作（題材・テーマ・誰に／何を／どう思われたいか）

決まっている語から選ぶ

入力して登録すると、既存の語でも新しい語でも印象タグに追加します。同じ語を複数回登録できます。

印象項目の候補語にも追加する

追加先を指定して登録すると、その項目の候補語として使えます。

新しい印象項目を作る
Web版GPTのまとめを取り込む

指定形式のJSONを含むMDを読み込みます。内容を確認してから、空欄と印象タグへ追加します。

Web版GPTへの依頼文

この文と依頼メールのやりとりをWeb版GPTへ渡してください。

以下の依頼メールのやりとりを読み、イラスト制作の初動に必要な情報を整理してください。推測で確定事項を作らず、不明な欄は空文字にしてください。印象の候補は candidate、明示的に決まった印象は adopted にしてください。メール本文をそのまま転載せず、要点だけ残してください。

返答はMarkdownで、次の形式のJSONコードブロックを必ず1つ含めてください。JSONのキー名と型を変えず、JSONとして有効な形で出力してください。「誰に」は絵の想定閲覧者、「何を」は伝えたい内容、「どう思われたいか」は見た人に残したい印象です。noteには依頼内容の要点、制作条件、未確定事項を簡潔にまとめてください。印象タグは {"text":"透明感","state":"candidate"} の形で配列に入れ、不要なら空配列にしてください。

```json
{
  "format": "theme-impression-memo-import",
  "version": 1,
  "fields": {
    "題材": "",
    "テーマ": "",
    "誰に": "",
    "何を": "",
    "どう思われたいか": "",
    "確定条件": "",
    "最終成果物の形": ""
  },
  "impressionTags": [],
  "note": ""
}
```

例の「透明感」は実際の依頼に根拠がない限り出力しないでください。メール上で食い違う情報は、勝手に決めず note に未確定事項として記してください。
